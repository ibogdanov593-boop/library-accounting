# Kanban-доска проекта

Доска создаётся в Trello или Kaiten с пятью колонками: **Backlog → To Do → In Progress → Review → Done**. Ниже зафиксировано её содержимое, чтобы его можно было перенести на доску и хранить вместе с кодом.

## Правила колонок

| Колонка | Что означает |
|---------|--------------|
| Backlog | Все известные задачи, ещё не взятые в итерацию |
| To Do | Задачи текущей итерации, готовые к выполнению |
| In Progress | Разработчик работает над задачей в feature-ветке |
| Review | Ветка отправлена в общий репозиторий, ждёт проверки |
| Done | Проверено и слито в `main` |
